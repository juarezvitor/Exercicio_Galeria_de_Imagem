# 📸 Galeria de Fotos

Aplicação web que exibe uma galeria de fotos utilizando uma API pública, permitindo a visualização, pesquisa e filtragem de imagens em tempo real com base em palavras-chave.

O projeto foi desenvolvido com foco em **usabilidade**, **organização visual em grid** e **interatividade**, atendendo aos requisitos propostos no enunciado.

---

## 🖼️ Funcionalidades

- Exibição de fotos em layout grid responsivo
- Carregamento inicial automático de imagens ao entrar na página
- Busca em tempo real conforme o usuário digita
- Pesquisa por palavra-chave utilizando API pública
- Mensagem informativa quando nenhuma imagem é encontrada
- Exibição do nome da imagem ao passar o mouse (hover)
- Em dispositivos móveis, o nome da imagem permanece visível
- Retorno ao estado inicial ao clicar no título da página

---

## 🚀 Tecnologias Utilizadas

- **HTML5** — Estrutura da aplicação
- **CSS3** — Estilização, layout grid, responsividade e efeitos visuais
- **JavaScript (ES6+)** — Lógica da aplicação, manipulação do DOM e consumo de API
- **API Unsplash** — Fonte das imagens exibidas
